# תמליל / מתווה סיור בחדר (מעובד)

מקור: סרטון סיור מדובר ~4 דק׳ + ניתוח ויזואלי.
הערה: קובץ Whisper הגולמי שמור בנפרד; כאן מתווה מסודר לפי סדר ההסבר.

1. פתיחה — סיום הקמת חדר המוזיקה / הטיפול.
2. תאורה חכמה — שלט בכניסה; מצבי האזנה / נגינה / רגיל.
3. טיפול אקוסטי — קירות, תקרה, באסים בפינות.
4. כלי נגינה — מתלה גיטרות + מגבר; Kawai; EFNOTE; HandSonic; בס; פסנתר ימאהה; מיקרופונים.
5. וילונות אקוסטיים — ספיגה ומניעת רעש למסדרון.
6. ארון תקשורת וציוד שמע.
7. שולחן בקרה ראשי + מחשב + HandSonic נוסף.
8. עמדת Atmos — 4 בתקרה, 7 ברצפה, סאב; כיסא מרכזי; חוויה חזקה.
9. שליטה מ־iPad — מאקרואים, תאורה, מיקסר.
10. סיום.
